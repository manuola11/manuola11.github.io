MLB Pitch Analytics Platform

In progress · Python · React · Statcast data

Status: in active development — an equal, two-person collaboration.

Repository. This is an open, in-progress build. Browse the code on GitHub. It runs on a deployed data pipeline, but there isn't a public demo URL yet.

What it is

A pitch-analytics platform built on Statcast pitch-by-pitch data. It ingests every pitch, processes it into queryable tables, and surfaces tactical scouting insights through an interactive web interface: empirical whiff and put-away rates for two-pitch sequences, batter vulnerabilities by pitch type and count, and the single pitch that offers the most leverage in a given pitcher–batter matchup.

Why

The project answers scouting-style questions that a season-level box score can't:

  • Which two-pitch sequences generate the highest whiff or put-away rates?
  • Where does a specific batter struggle most against particular pitch types, counts, and locations?
  • Which single pitch offers the highest leverage in any pitcher–batter matchup?

Stack

  • Data: Statcast (2015–2026), ingested with the pybaseball library in chunked, rate-limited weekly pulls
  • Backend: Python — a FastAPI REST API and DuckDB running embedded SQL over Parquet columnar storage, with Typer CLI tooling
  • Frontend: React + Vite
  • Modeling: empirical-Bayes shrinkage to stabilize rate estimates against small samples (raw, league-baseline, and shrunk variants)
  • Infrastructure: deployed on an Ubuntu ARM VM with systemd services running nightly ingestion

Progress & findings so far

  • A working data pipeline ingests and compresses roughly 1.4 GB of raw Statcast data into Hive-partitioned Parquet, with derived tables rebuilt on top.
  • Seven derived tables power the analyzers — pitcher pitch mix, zone tendency, and sequences; batter whiff profile, swing decisions, and sequence outcomes; and matchup edges.
  • Three analyzers are working in the app: a pitch-sequence viewer (pitcher and batter perspectives), a matchup edge detector that surfaces the top leverage pairings, and an ad-hoc SQL shell.
  • An early study looks at first-pitch offspeed — whether hard throwers (96+ mph) get better called-strike-plus-whiff (CSW%) results leading at-bats with offspeed pitches than soft throwers.
